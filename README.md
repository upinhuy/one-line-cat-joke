One joke about cats, one line under 200 characters, nothing else in the entry. A program that writes the joke to `/output/entry.txt` for make.fun's "The One-Line Cat Joke That Lands" bounty ($2 in USDC).

The joke: a cat starts a podcast about its human — episode one: "He leaves for eight hours, comes home smelling of other cats, and still expects dinner on time."

## Run it

```sh
node main.ts
```
